# SEA-Scanning-And-Enumeration-Automation-Tool-
The Scanning and Enumeration Automation (SEA) system that will provide the ability to standardize and automate the use of selected scanning and enumeration tools, including customized software and scripts, run custom commands per tool, report results to the analysts in a useful manner, and export results in XML format.

The Software Configuration Management (SCM) plan will specifically address configuration management for the Scanning and Enumeration Automation Tool (SEA Tool). The Scanning and Enumeration Automation Tool is the system that is going to be developed in order to assist the Data & Analysis Center (DAC) by standardizing scanning and enumeration routines and save time by gathering available scanning and enumeration tools in one place for a much more efficient reconnaissance of scanned data through automation. Configuration management for the SEA tool and other components managed will be managed by the development team and to be addressed by the Data & Analysis Center Analyst.
